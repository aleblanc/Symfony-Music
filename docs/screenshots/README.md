# Screenshots

Taken on a separate demo database (never `var/library/music.db`) filled with
royalty-free content only:

- **Real Creative Commons releases**: Nine Inch Nails — *The Slip* and
  *Ghosts I–IV* (CC BY-NC-SA 3.0); Kimiko Ishizaka — *Open Goldberg
  Variations* (CC0).
- **Fictional artists** invented for the demo: Ashen Crown, Velvet Static,
  The Paper Satellites, Neon Harbor, Les Chats Bleus, Northbound Owls,
  Glass Tundra, Luna Fold, Marée Basse, Kettle & Kite.
- **Every image is generated** (ImageMagick gradients): album covers, artist
  photos, discography covers, video thumbnails. No third-party artwork.
- Play counts, ratings, listeners, import candidates, suggestions and
  quality figures are made up.
